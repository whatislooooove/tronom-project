Идея проекта появилась, когда я не смог найти приложение-метроном, где можно было бы созданные песни (точнее настроенный метроном под конкретную песню) раскидать по папкам. В маркетах условно-бесплатные приложения не понравились - где то нужна подписка для такой функции, где-то нету возможности группировки, а где-то вовсе можно хранить 5 песен. 

Очередной микро пет-проект...
