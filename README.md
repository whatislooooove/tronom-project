# 🥁 Catronom: Профессиональный Метроном с Bongo Cat

![Bongo Cat](app/src/main/res/drawable/cat_idle.png)

**Catronom** — это высокоточный Android-метроном, созданный специально для музыкантов, которым важна не только стабильность ритма, но и удобство организации своих репетиций. Главной особенностью приложения является легендарный **Bongo Cat**, который «барабанит» вместе с вами точно в такт!<br><br>

## 🚀 Особенности проекта

### 🐱 Интерактивный Bongo Cat
*   Визуализация ритма в реальном времени
*   **Сильная доля:** Кот хлопает обеими лапками
*   **Слабые доли:** Кот использует правую лапку

### ⏱️ Безупречная точность
*   Использование профессионального аудио-движка (режим потоковой передачи байтов)
*   Расчет времени на основе аудио-сэмплов (44100 Гц) исключает любой дрейф темпа
*   Приоритет аудио-потока реального времени для стабильной работы под нагрузкой

### 📂 Зарождение проекта
Идея проекта появилась, когда я не смог найти приложение-метроном, где можно было бы созданные песни (точнее настроенный метроном под конкретную песню) раскидать по папкам. В маркетах условно-бесплатные приложения не понравились - где то нужна подписка для такой функции, где-то нету возможности группировки, а где-то вовсе можно хранить 5 песен. Поэтому фича у этого приложения в следующем:

*   **Группировка по папкам:** Создавайте сеты для разных групп или выступлений
*   **Полное сохранение:** Пресет хранит не только BPM, но и музыкальный размер (4/4, 7/8 и т.д.)
*   **Импорт/Экспорт:** Мгновенный бэкап всей вашей библиотеки в JSON

## 🛠 Технологический стек

*   **UI:** Jetpack Compose (Modern Declarative UI)
*   **Database:** Room (с поддержкой миграций и экспорта)
*   **Audio:** Высокопроизводительный движок на Kotlin/Android AudioTrack (Stream Mode)
*   **Architecture:** Clean Architecture + MVVM + Manual DI (AppContainer)
*   **Performance:** Оптимизированная отрисовка анимаций через стейт-машину.
